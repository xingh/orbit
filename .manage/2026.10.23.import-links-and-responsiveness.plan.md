# Session plan — 2026.10.23

Work completed and **not yet committed**. Recorded here so the reasoning survives even if the diff
is reviewed later or rebased. Move to `.archive/` once committed.

## 1. Project links on imported chats

Nothing was related to anything: all 1055 imported chats had `projectId: ""`. Two independent
causes, each sufficient — no scanner read a project reference from a chat row, and the service
forced the field blank.

Now: each service's projects are read before its chats; a chat carries `project_uuid`/`project`/a
`g-p-` gizmo through; a project list that names its own conversations files them when the chat list
says nothing; and the service keeps a link only when the project really exists — never under
another chat, never nested. Rules in `.knowledge/import.reconciliation.md`.

## 2. Re-import repairs existing data

A duplicate used to be counted and discarded, so every earlier chat would have stayed loose
forever. The merge now fills a *missing* link on an already-saved chat, reports it as `linked`, and
touches nothing else. A link already in place is never moved.

## 3. ChatGPT project list was truncated at five

The trace showed `/backend-api/gizmos/snorlax/sidebar` returning `items|cursor` and being called
exactly once — the list is cursor-paged. Every page is followed now, stopping on a missing or
repeated cursor.

## 4. A write-back race, found while testing the above

Four batches posted back to back lost one, and a later batch re-added its chat **without its
project**. The window saves the whole workspace and built its JSON *before* taking the storage
lock, while the service reads-merges-writes *under* it. Nothing errored.

`save_data` now keeps any stored entry the window neither sent nor names as deleted, deletions are
reported explicitly, and a queued save writes the freshest state. See knowledge principle 7.

## 6. The 3D robot is optional

A `robot` setting (default on), a Preferences switch, `Robot.tsx` lazy-loaded so Three.js lands in
its own 482 KB chunk that is never fetched when off, a flat mark in its place, and ~100px of window
height given back. Groundwork for `issue.0017.robot-genome.md`.
