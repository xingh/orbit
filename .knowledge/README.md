# Knowledge

What is true about Orbit regardless of what is currently built or planned. Principles, the
vocabulary, and reference material that outlives any one release.

If a statement here stops being true, it was never knowledge — move it to `.arkitype/` (how this
system is constituted) or `.manage/` (what we intend to do about it).
